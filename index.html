Subvox Android

1-NN dynamic time warping over 10 kinematic channels, with leave-one-out accuracy and a 500× label-permutation p-value, on-device. Android Head Tracker HID support for compatible Bluetooth headsets (Sony WH/WF-1000XM5, XM6, ULT WEAR).

Build

git clone https://github.com/OWNER/subvox-android.git
cd subvox-android
./gradlew --no-daemon assembleDebug

APK: app/build/outputs/apk/debug/app-debug.apk
