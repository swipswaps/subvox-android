Subvox Android

A native Android port of joeblau/subvox: 1-NN dynamic time warping over 10 kinematic channels, with a leave-one-out accuracy and a 500× label-permutation p-value, all on-device.

Build

git clone https://github.com/OWNER/subvox-android.git
cd subvox-android
./gradlew --no-daemon assembleDebug

APK: app/build/outputs/apk/debug/app-debug.apk

Install

adb install -r app/build/outputs/apk/debug/app-debug.apk

Or download the subvox-debug-apk artifact from the Actions tab.
